# Royal Care - Medical Asset & Maintenance System

An enterprise mobile solution designed for hospital biomedical asset tracking, preventive maintenance, and fault management.

---

## 📱 Features & Screenshots

### 1. Authentication & Role-Based Access
Secure login supporting multiple roles (Admin, Technician, User) with granular permissions.
![Login](01_login.jpg)

### 2. Analytics Dashboard & Navigation
Interactive dashboard showing real-time statistics for total assets, active items, maintenance costs, and work orders.
![Dashboard](02_dashboard.jpg)
![Navigation Menu](03_menu.jpg)

### 3. Medical Asset QR/Barcode Scanner
Integrated scanner for instant hardware identification and inventory auditing.
![QR Scanner](07_qr_scan.jpg)

### 4. Preventive Maintenance (PM) Scheduler
Monitors compliance rates, overdue maintenance, calibration schedules, and logs completion status.
![PM Scheduler](04_pm_scheduler.jpg)

### 5. Smart Excel Data Parser & User Management
Enables bulk importation of asset registries and seamless management of system users and departments.
![Smart Excel Import](05_excel_import.jpg)
![User Management](06_add_user.jpg)
![Settings](08_settings.jpg)

---

## 🛠 Tech Stack & Architecture

- **Architecture:** Clean Architecture / MVVM
- **UI/UX:** Responsive Material/Cupertino Design
- **Core Integrations:** Barcode/QR Scanner, Excel Sheet Parser, Preventive Maintenance Scheduler
